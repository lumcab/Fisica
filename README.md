# ⚛️ Laboratorio Virtual de Física | I.E. Paulo VI

Bienvenido al repositorio oficial de herramientas digitales para la asignatura de **Física** (Educación Media: Grados 10° y 11°).

Este proyecto tiene como objetivo complementar las clases presenciales con aplicaciones web interactivas, simuladores y calculadoras diseñadas para facilitar la comprensión de los fenómenos físicos, desde la mecánica clásica hasta el electromagnetismo.

## 🚀 Contenido del Repositorio

Aquí encontrarás una colección de herramientas web organizadas por grado y temática:

### 📘 Grado 10°: Mecánica Clásica
Enfocado en el estudio del movimiento y las fuerzas.
* **Fundamentos:** Historia, Método Científico y Conversión de Unidades.
* **Cinemática:** Simuladores de movimiento rectilíneo y parabólico.
* **Dinámica:** Calculadoras para las Leyes de Newton.
* **Energía:** Conservación de la energía mecánica.

### 📙 Grado 11°: Física II
Enfocado en ondas, energía térmica y campos.
* **Termodinámica:** Escalas de temperatura y gases ideales.
* **Ondas y Óptica:** Simuladores de sonido, luz y espejos.
* **Electromagnetismo:** Ley de Coulomb, Circuitos (Ley de Ohm) y Magnetismo.
* **Física Moderna:** Introducción a conceptos cuánticos básicos.

## 🛠️ Tecnologías y Filosofía

Estas herramientas son de **Código Abierto (Open Source)** y han sido desarrolladas utilizando estándares web modernos para garantizar el acceso democrático a la tecnología educativa.

* **Lenguajes:** HTML5, CSS3 (Tailwind), JavaScript.
* **Librerías:** MathJax (Fórmulas), Chart.js (Gráficos).
* **Enfoque:** *Mobile-first* (Pensado para pantallas de celular).
